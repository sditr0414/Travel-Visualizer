# 설치형 지도

[프로그램 소개](../README.md) · [문서 목록](../docs/README.md)

기본 배경은 온라인 지도입니다. 이 PC에 PMTiles를 설치해 사용하려면 저장소 최상위에서 실행합니다.

```sh
npm run map:setup
```

설치 스크립트는 PMTiles CLI와 지도 원본을 준비하고 아래 파일을 `maps/`에 생성합니다. 다운로드에는 인터넷과 충분한 디스크 공간이 필요합니다.

| 파일 | 범위 |
| --- | --- |
| `world-z5.pmtiles` | 전 세계 저배율 개요, z0~5 |
| `korea-japan-z14.pmtiles` | 한국·일본 기본 상세 영역, 최대 z14 |

완료 후 앱의 **여행 설정 → 배경 지도**에서 **설치형 지도**를 선택합니다. 설치 전에는 **설치형 지도 · 설치 필요**로 표시됩니다. 파일은 Git에 커밋하지 않습니다.

기존 파일은 다시 다운로드하지 않습니다. 다시 준비하려면 `npm run map:setup:force`를 사용합니다. 이 명령은 기존 지도 파일을 교체하므로 다운로드할 수 있는 연결에서 실행하세요.

## 설치 범위 변경

상세 영역의 기본 경계는 `125.3,32.3,137.5,38.3`입니다. 경도 최소·위도 최소·경도 최대·위도 최대 순서로 `TRAVEL_MAP_BBOX`를 지정합니다. 파일명은 영역을 바꿔도 유지됩니다.

```sh
TRAVEL_MAP_BBOX='125.3,32.3,137.5,38.3' npm run map:setup
```

`PROTOMAPS_BUILD_URL`로 사용할 PMTiles 원본 URL을 지정할 수 있습니다. 기본은 접근 가능한 Protomaps 빌드를 확인하고 Source Cooperative 미러로 대체합니다. 이미 설치한 상세 영역을 바꿀 때는 다시 준비하는 명령을 사용하세요.

## 오프라인 사용 범위

상세 지도는 설치한 영역에 한정됩니다. 한국어·다국어 지명 글꼴은 필요한 범위를 최초 사용할 때 받아 `.cache/map-glyphs/`에 저장합니다. 아직 캐시되지 않은 글꼴은 인터넷이 필요할 수 있어 모든 지역을 처음부터 완전히 오프라인으로 표시하지는 않습니다.

`TRAVEL_GLYPH_CACHE_DIR`로 캐시 위치를, `TRAVEL_GLYPH_BASE_URL`로 glyph 공급 위치를 바꿀 수 있습니다. 설치형 지도와 이 글꼴 API는 로컬 Node 서버에서 제공합니다. `dist/`만 올린 정적 호스팅에서는 사용할 수 없습니다.
