# Travel Camera

[**Travel Camera 웹에서 열기**](https://sditr0414.github.io/Travel-Visualizer/)

Google 지도 타임라인과 내 사진·영상으로 여행을 다시 보는 웹앱입니다. PC와 휴대폰의 브라우저에서 설치 없이 사용합니다.

## 시작하기

1. **타임라인 파일 열기**로 Google 지도에서 내보낸 JSON을 선택합니다.
2. 추천 여행을 고르거나 **여행 설정**에서 감상할 기간을 지정합니다.
3. **사진 폴더 선택** 또는 **사진·영상 파일 선택**으로 내 파일을 연결하고 감상합니다. 타임라인만으로 경로를 볼 수도 있습니다. 정리된 이동 구간 없이 원시 위치 기록만 있는 내보내기 파일도 지원합니다.

화면에는 자신의 파일을 선택한 뒤 여행이 표시됩니다. 사진·타임라인 샘플이나 미리보기는 제공하지 않습니다. 배경 지도는 인터넷으로 불러옵니다.

## 감상과 저장

- **경로 보기**: 이동 경로와 현재 위치, 이동수단·시각·속도·거리를 봅니다. 처음과 마지막에는 여행 전체를 요약합니다.
- **사진 여정**: 지도와 사진·영상을 촬영 순서대로 감상합니다. 두 모드는 각각 보던 위치를 기억하고, 지도와 사진의 화면 비율을 조절할 수 있습니다.
- **여행 설정**: 기간과 지도 확대를 조절합니다. 세부 옵션은 **사진·영상 설정**, **경로 재생 설정**에서 펼칩니다.
- **사진 목록 관리**: 파일명·날짜로 찾기, 장면 이동, 감상에서 제외하기, 촬영 시간대 조정을 지원합니다. 원본은 바꾸지 않습니다.
- **여행 저장·열기**: 기간·설정·제외한 사진·재생 위치를 프로젝트 JSON으로 저장합니다. 다음 실행에서는 프로젝트와 원본 파일을 다시 선택해 복원합니다.

## 파일과 개인정보

타임라인과 사진·영상 원본은 기기의 브라우저에서 처리하며 외부로 업로드하지 않습니다. 온라인 지도 요청에는 보고 있는 영역과 미리 불러올 주변 영역이 반영됩니다.

프로젝트 JSON에는 원본 본문이나 GPS 좌표가 들어가지 않지만, 여행 날짜·파일명·상대 폴더명·크기·수정 시각·타임라인 해시가 포함됩니다. 개인 자료로 보관하세요. 새로고침하면 원본 파일을 다시 선택해야 합니다.
