# 작업 시작 안내 — Travel Camera

1. 현재 브랜치·작업 트리·원격 `main`을 확인합니다. `main`은 최신 변경을 담고 `v3`는 UI 개선 전 `7dd7502`를 보존합니다. 상시 브랜치는 둘만 사용하며 새 변경을 `v3`에 동기화하지 않습니다.
2. [프로그램 소개](../README.md), [개발 안내](DEVELOPMENT.md), [구현 계약](AI_PROJECT_CONTEXT.md)을 읽고 변경에 관련된 데이터 계약을 확인합니다. [v3 릴리스 기록](archive/V3_RELEASE_NOTES.md)은 과거 설명입니다.
3. 검증 범위는 사용자 요청과 변경 위험에 맞춥니다. UI는 실제 렌더링·접근성과 lint/build를 확인하고 기존 회귀 검사를 재사용합니다. 검사 통과 후 새 변경이나 우려 없이 반복하지 않습니다.
4. 기존 전체 화면 지도·사진 분할·접이식 설정과 경로·카메라 엔진을 유지합니다. 색상과 스타일의 원본은 앱 CSS입니다. 도움말과 사진 목록은 공통 Dialog를 사용합니다.
5. 개인 타임라인·사진 원본·위치 fixture·메타데이터 캐시를 커밋하지 않습니다. 공개 촬영 자료는 사용자가 허용한 결과물만 `docs/assets/`에 두며 범위는 [MEDIA.md](MEDIA.md)에 기록합니다. 이를 추가 개인 자료의 공개 허가로 해석하지 않습니다.
6. 최상위에는 소개·실행 진입점·표준 탐색 설정만 둡니다. 세부 도구 설정은 `config/`, 서버는 `server/`, 보조 실행은 `scripts/`, 문서는 `docs/`를 사용합니다. 경로를 바꾸면 런처·빌드 fingerprint·테스트 설정·문서 링크를 함께 확인합니다.

사용자 동작과 구현 계약이 달라지면 해당 문서를 같은 변경에서 갱신합니다. 세부 문서의 역할은 [문서 목록](README.md)을 따릅니다.
