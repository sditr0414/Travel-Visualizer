# 사용 안내

[프로그램 소개](../README.md) · [문서 목록](README.md)

## 웹에서 시작하기

[Travel Camera 열기](https://sditr0414.github.io/Travel-Visualizer/)에서 설치 없이 사용합니다. PC와 휴대폰 모두 같은 주소로 접속합니다.

1. **타임라인 파일 열기**로 자신의 타임라인을 선택합니다.
2. 추천 여행을 고르거나 **여행 설정**에서 기간을 지정합니다.
3. **사진 폴더 선택** 또는 **사진·영상 파일 선택**으로 파일을 연결한 뒤 **재생**을 누릅니다.

사진 없이 경로만 감상할 수도 있습니다. 샘플 여행과 사진·타임라인 미리보기는 포함하지 않습니다. 파일을 선택하기 전에는 지도도 불러오지 않습니다. 타임라인 준비 방법은 첫 화면의 같은 이름 버튼에서 확인하세요.

## 여행 파일 연결

스마트폰 Google 지도에서 내보낸 `semanticSegments` 형식의 JSON을 **타임라인 파일 열기**로 선택합니다. 직접 선택하는 파일은 250MB 이하입니다. 기록에서 추천 여행을 골라 경로를 준비하며, 추천이 없으면 전체 기간을 사용합니다.

사진과 영상은 첫 화면의 **사진 폴더 선택** 또는 **사진·영상 파일 선택**으로 연결합니다. 여행 설정에서도 **폴더 선택**·**파일 선택**을 사용할 수 있습니다. 분석 중에는 **사진 연결 취소**로 중단하고 **사진 다시 연결**로 재시도합니다. 취소하거나 사진이 없는 폴더를 선택해도 기존 사진 목록은 유지됩니다. Takeout의 JSON 보조 파일을 함께 선택하면 촬영 정보를 보완합니다.

선택한 파일은 기기의 브라우저에서 읽으며 서버로 업로드하지 않습니다. 새로고침 후에는 원본을 다시 선택해야 합니다. 기간·설정·사진 제외 상태·재생 위치를 보관하려면 아래의 프로젝트 저장을 사용하세요.

## 감상하기

**경로 보기**는 전체 화면 지도에서 이동을 따라갑니다. 이동수단, 날짜·시각, 속도와 **현재 개별 이동의 거리**를 표시합니다. 같은 이동수단을 여러 번 이용해도 서로 다른 이동은 각각 보여줍니다. 기록 사이의 공백은 앞뒤 이동과 거리·시간·방향을 참고해 수단과 속도를 보완합니다. 보완한 거리는 가장 비슷한 인접 이동 한쪽에 포함합니다. 참고 정보가 전혀 없는 속도는 `—`로 표시합니다.

**사진 여정**은 지도 옆에서 사진·영상을 촬영 순서대로 보여줍니다. 사진과 날짜 장면에서 머무는 시간이 전체 재생 시간에 포함됩니다. 짧은 영상은 장면이 끝날 때까지 마지막 프레임을 유지합니다. 브라우저가 자동 재생을 막으면 영상 안의 재생 버튼을 누르세요.

두 모드는 각각 보던 위치를 기억합니다. **전체 경로**는 재생 위치를 바꾸지 않고 여행 동선을 화면에 맞춥니다. **처음부터 보기**는 전체 여정 요약을 보여주고 재생을 기다립니다. 여정을 불러온 직후와 마지막 **여행 전체**에도 여행 기간·총 일수·전체 거리·수단별 거리와 비중을 표시합니다. 제외한 항공 구간은 합계에서 빠집니다.

**일시정지 시 전체 경로 표시**는 기본으로 꺼져 있습니다. 멈춘 장면에는 현재 위치와 최근 경로만 남습니다. 여행 설정에서 켜면 전체 동선도 함께 표시하며, 두 모드에 즉시 적용되고 다음 실행에도 기억합니다. **전체 경로** 버튼과 처음·마지막의 여행 전체 화면은 이 옵션과 관계없이 전체 동선을 보여줍니다.

PC는 지도와 사진을 좌우로, 820px 이하 화면은 위아래로 배치합니다. 분할선을 드래그하거나 키보드로 조절할 수 있습니다. 작은 화면에서는 지도 버튼과 재생 컨트롤이 겹치지 않도록 지도 영역의 최소 높이를 확보합니다.

지도 빈 영역을 한 번 클릭하거나 탭하면 현재 모드의 재생·일시정지가 전환됩니다. 더블클릭·두 번 탭 확대와 구분하므로 약 0.5초 뒤 반응합니다. 지도 드래그·휠·두 손가락 확대, 지도 버튼 조작은 재생 상태를 바꾸지 않습니다.

PC에서는 하단 장면 정보가 기본으로 표시됩니다. **여행 설정 → 경로 재생 설정 → 현재 장면 하단에 표시**에서 끌 수 있습니다. 경로 보기의 재생바 위에 이동 수단·속도·거리, 지도에서 확인한 이동 지역, 여행 날짜·시각과 구간 시작·종료 시각을 표시합니다. 시각은 한국 시간이며, 지역명은 지도에 로드된 주변 도시 기준입니다. 하단 정보가 보이면 왼쪽 상단의 현재 장면은 부드럽게 숨기며, 하단 표시를 끄거나 모바일 화면으로 바꾸면 다시 나타납니다. 처음·마지막 여행 전체 요약은 유지합니다. 재생바가 숨겨지면 하단 정보가 화면 아래로 부드럽게 내려가고, 재생바가 나타나면 위로 올라옵니다. PC에서는 상단 약 104px와 재생바보다 넓은 하단 영역에 마우스를 옮겨 컨트롤을 쉽게 다시 표시할 수 있습니다. 사진 여정의 하단 감지 영역은 지도 안에만 놓입니다. 표시 여부는 설정·프로젝트에 저장되며 기존에 저장한 선택은 유지합니다. 820px 이하에서는 기존 배치를 유지합니다.

## 온라인 지도

지도는 OpenFreeMap에서 자동으로 불러옵니다. 별도의 지도 파일이나 API 키를 준비할 필요가 없으며, 배경 지도에는 인터넷 연결이 필요합니다. 처음 연결에 실패하거나 12초 이상 응답하지 않으면 단색 배경에 로컬 경로와 사진을 표시합니다. 인터넷 연결이 돌아오면 **지도 다시 연결**을 누르세요.

재생할 때는 약 1.4초 뒤에 보여줄 위치의 지도 타일을 미리 불러옵니다. 지도 버튼·마우스 휠·터치로 확대하거나 축소할 때도 진행 방향의 다음 확대 단계를 준비합니다. 이미 받은 타일은 브라우저와 지도 엔진의 캐시를 재사용합니다.

미리 불러오기는 로딩 지연을 줄이는 기능입니다. 새 지역으로 크게 이동하거나 빠르게 확대·축소할 때, 인터넷이 느릴 때는 지도가 늦게 표시될 수 있습니다. 타일을 받은 뒤의 글꼴 처리와 화면 렌더링까지 미리 완료하는 방식은 아니며 배경 지도의 오프라인 사용을 보장하지 않습니다. 단색 배경에서는 도로·지명 없이 경로와 사진을 감상할 수 있습니다.

## 여행 저장과 복원

1. 여행 기간·재생 구성을 변경했다면 **경로 다시 만들기**로 적용합니다.
2. **여행 설정 → 여행 저장·열기**에서 이름을 입력하고 **프로젝트 파일 저장**을 누릅니다. 브라우저 다운로드 폴더의 `.travel-camera.json` 파일을 보관하세요.
3. 다음 실행에서 **저장한 여행 열기** 또는 설정의 **여행 저장·열기**로 이 파일을 선택합니다.
4. 현재 원본이 연결되어 있으면 **이 여행 복원**을 누릅니다. 다른 기기나 직접 파일 선택 방식에서는 타임라인 원본과 사진·영상 폴더를 다시 선택한 뒤 복원합니다.

기간·감상 설정·사진 제외 상태·두 감상 모드의 재생 위치·화면 분할 비율을 복원합니다. 모든 원본 확인과 경로 준비가 끝나기 전에는 기존 여행을 교체하지 않습니다. 잘못된 파일·누락된 사진이 있으면 원래 폴더를 다시 선택하세요. 복원 중 **복원 취소**나 대화상자 닫기로 중단할 수 있습니다. 일반 타임라인 교체도 실패·취소 시 기존 여행을 유지합니다.

프로젝트 파일은 원본을 포함하지 않으므로 원본과 함께 따로 보관해야 합니다. 원본 타임라인은 내용이 같아야 하고 사진은 파일명·크기·수정 시각이 같아야 합니다. 수정 시각을 바꾼 복사본은 확인에 실패할 수 있습니다. 시간대 없는 사진 정보는 촬영 시간대 설정으로 해석하며, 프로젝트에 저장한 해석 시간대도 복원합니다. 로컬 전용인 정확한 장소 온라인 확인은 복원 시 꺼집니다. 프로젝트 파일은 최대 10 MB, 사진 목록은 최대 20,000개입니다.

## 여행 설정

설정을 열면 재생이 일시정지합니다. 기간·추천 여행·지도 확대와 파일 연결을 먼저 보여주며, 세부 옵션은 **사진·영상 설정** 또는 **경로 재생 설정**을 눌러 펼칩니다. 사진 연결과 **사진 목록 관리**는 경로 보기에서도 사용할 수 있습니다.

이름에 마우스를 올리거나 키보드로 이동하면 설명이 열립니다. 마우스가 이름을 벗어나면 설명이 닫히고, 클릭·탭으로 고정한 설명은 다시 누르거나 바깥을 누르면 닫힙니다. 체크 항목은 실제 네모 칸을 눌러 변경합니다.

| 설정 | 적용 |
| --- | --- |
| 여행 기간·추천 여행 | 날짜를 선택하고 **경로 다시 만들기** |
| 지도 보기 방식·구간별 재생 시간·경로 재생 시간·항공 경로 포함 | **경로 다시 만들기** |
| 지도 확대·현재 위치 따라가기·일시정지 시 전체 경로 표시 | 즉시 |
| 대표/모든 사진·사진 표시 시간·사진 위치 확대 | 즉시 |
| 날짜 변경 표시·날짜 표시 시간 | 즉시 |
| 영상 자동 재생/첫 화면·소리·최대 재생 시간 | 즉시 |
| 정확한 장소 온라인 확인 | 로컬 실행에서 서비스를 설정한 경우만 즉시 |

경로 재생 시간은 여행 규모에 맞는 범위 안에서 조절합니다. **사진 목록 관리**에서는 촬영 시각의 출처와 GPS 또는 타임라인으로 보완한 위치를 확인하고 이번 감상에서 제외할 파일을 고릅니다. 원본은 바뀌지 않습니다. 제외 상태는 새로고침하면 초기화되므로 유지하려면 **여행 저장·열기**에서 프로젝트 파일로 저장하세요.

## 단축키

| 키 | 동작 |
| --- | --- |
| `Space` | 재생·일시정지 |
| `←` / `→` | 5초 뒤로·앞으로 |
| `Home` | 처음으로 |
| `Esc` | 열린 설정·대화상자 닫기 |

입력란에서는 원래 키 동작을 유지합니다. 다른 탭으로 이동하면 재생을 멈춥니다. 운영체제의 모션 줄이기·고대비 설정도 지원합니다.

## 문제가 있을 때

| 증상 | 확인할 내용 |
| --- | --- |
| 타임라인을 열 수 없음 | `semanticSegments` 형식·파일 크기·JSON 유효성 확인 |
| 사진이 보이지 않음 | 여행 기간과 촬영 시각, 사진 목록의 제외 상태 확인 |
| 파일 표시 실패·영상 화면 없음 | HEVC 등 미지원 코덱은 소리만 읽힐 수 있습니다. 사진은 JPEG·PNG, 영상은 H.264 MP4 변환 사본으로 선택하세요. 원본은 보존하세요. |
| 지도가 늦게 뜸 | 네트워크 상태를 확인하고 로딩 안내의 다시 연결 사용 |
| 설정을 바꿔도 경로가 같음 | 하단 **경로 다시 만들기**로 적용해야 하는 항목인지 확인 |

화면 시각과 날짜 범위는 한국 시간(UTC+9)입니다. 시간대가 없는 촬영 정보는 **촬영 시간대 조정** 설정을 따르며 기본값은 기기 시간대입니다. 파일 시각과 화면 표시가 다르면 이 차이도 확인하세요.

웹에서는 기본 폴더 자동 연결·영상 변환·정확한 장소 온라인 조회를 제공하지 않습니다. 이 기능이 필요하면 아래의 로컬 실행 안내를 따르세요.

## 사진 찾기와 촬영 시간대

**여행 설정 → 사진 목록 관리**에서 파일명 검색, **날짜로 이동**, 포함 상태를 함께 사용할 수 있습니다. 검색은 현재 여행 기간 안의 전체 목록에 적용하며 제외한 사진도 찾을 수 있습니다. **모두 포함하기**는 검색 결과와 관계없이 전체 목록에 적용됩니다. **장면 보기**를 누르면 모든 사진 모드로 전환하여 해당 사진에서 일시정지합니다. 제외한 사진은 먼저 체크해 포함하세요. 검색 조건 자체는 프로젝트에 저장하지 않습니다.

목록과 날짜 필터는 한국 시간(UTC+9)을 기준으로 표시합니다. **촬영 시간대 조정**은 시간대 없는 EXIF 날짜·영상 날짜·파일명을 어떤 시간대로 해석할지 정합니다. `Asia/Tokyo`, `America/Los_Angeles`처럼 지역 이름을 쓰거나 `+09:00`처럼 고정 차이를 지정할 수 있습니다. `DEVICE`는 현재 기기 시간대입니다. 시간대가 명시된 값과 QuickTime·Takeout의 절대 시각, 파일 수정 시각은 이동하지 않습니다. 적용 중 취소하면 기존 해석을 유지합니다. 감상 기본 설정 초기화는 촬영 시간대를 바꾸지 않습니다.

서머타임으로 시각이 두 번 나타나면 앞선 시각을 선택하며, 존재하지 않는 시각은 다음 촬영 정보나 파일 수정 시각으로 넘어갑니다. 이런 구간의 촬영 시각을 확실히 아는 경우 고정 시간 차이를 지정하세요. 프로젝트 저장 시 실제 해석 시간대를 함께 저장하며 기존 v1 파일도 당시 기록한 시간대로 복원합니다. 시간대 변경으로 여행 기간 밖으로 이동한 사진은 목록에서 빠질 수 있습니다.

## 로컬 실행과 종료

기본 폴더 자동 연결·영상 변환·직접 설정한 온라인 장소 조회가 필요하면 로컬 서버를 실행합니다. 웹 이용에는 설치가 필요하지 않습니다.

Node.js 24 이상과 Git을 설치한 뒤 실행합니다.

```sh
git clone https://github.com/sditr0414/Travel-Visualizer.git Travel-Visualizer
cd Travel-Visualizer
npm ci
npm start
```

기본 주소는 `http://127.0.0.1:5517`입니다. `npm start`는 변경된 소스가 있을 때만 배포 화면을 빌드합니다. 서버를 실행한 터미널에서 `Ctrl+C`를 누르면 종료됩니다. 런처는 자신이 시작한 서버의 준비 완료를 확인한 뒤 브라우저를 열며, 포트를 다른 프로그램이 사용 중이면 해당 프로그램을 열지 않고 종료합니다.

| 명령 | 동작 |
| --- | --- |
| `npm start` | 현재 코드의 배포 화면 실행 |
| `npm run launch` | 조건부 업데이트·의존성 설치 후 실행, 브라우저 열기 |
| `npm run launch:no-update` | 자동 업데이트 없이 런처 실행 |
| `npm run dev` | 소스 수정이 반영되는 개발 서버 |
| `npm start -- --port 5520` | 다른 포트에서 실행 |
| `npm start -- --no-local-data` | 개인 파일 자동 연결 끄기 |

런처는 Git 저장소의 `main`에서 추적 중인 수정이 없을 때만 `git pull --ff-only origin main`을 실행합니다. 다른 브랜치·로컬 수정·업데이트 실패 시 현재 파일로 실행합니다. ZIP에는 Git 이력이 없어 자동 업데이트를 하지 않습니다. 의존성은 첫 실행 또는 lockfile 변경 시 설치합니다.

Windows에서는 최상위 `TravelCamera.cmd`를 실행합니다. 바탕 화면 바로가기를 만들려면 `scripts/Install-TravelCamera-Shortcut.cmd`를 한 번 실행하세요. 바로가기의 대상은 최상위 런처입니다.

매번 선택하지 않으려면 다음처럼 저장소와 개인 파일을 같은 상위 폴더에 두세요.

```text
Travel-Visualizer/
├── 타임라인.json
├── 여행 사진/
└── Travel-Visualizer/     ← Git 저장소, 여기서 npm start
    ├── README.md
    ├── package.json
    └── src/
```

저장소 안에도 같은 이름의 파일·폴더가 있으면 그쪽을 먼저 읽습니다. 경로 지정 환경변수는 [파일과 개인정보](PRIVACY.md#로컬-파일-위치)에 정리했습니다. 개인 원본은 Git에서 제외되며 직접 선택한 파일은 새로고침 후 다시 선택해야 합니다.

휴대폰에서는 PC의 `127.0.0.1`에 접속할 수 없습니다. 휴대폰에서는 [웹 주소](https://sditr0414.github.io/Travel-Visualizer/)를 사용하세요. 로컬 포트가 사용 중이면 서버를 종료하거나 `--port 5520`을 지정합니다.

## 로컬 영상 한 개의 호환 사본

기본 사진 폴더의 영상은 사진 목록에서 **호환 사본**을 눌러 H.264 사본을 만들 수 있습니다. 로컬 컴퓨터에 `ffmpeg`와 `ffprobe`가 있어야 하며 자동 설치하지 않습니다. 직접 선택한 브라우저 파일과 정적 웹 호스팅에서는 이 기능을 사용할 수 없습니다.

기본값은 **첫 5초만 호환성 확인**입니다. 미리보기 재생을 확인한 뒤 필요하면 **선택한 영상 전체**를 선택하세요. 한 번에 영상 한 개만 처리하며 전체 목록을 자동 변환하지 않습니다. HDR은 별도의 색상 변환 설정이 필요하므로 이번 기능에서 거부합니다. 사본은 원본 품질 보관용이 아닌 H.264/AAC 감상용 압축 파일입니다.

진행률을 표시하고, **사본 만들기 취소**나 창 닫기로 중단할 수 있습니다. 미완성 사본은 정리합니다. 완료된 사본은 `.cache/compatible-media/copy-…/`에 남고 원본 파일을 수정하거나 덮어쓰지 않습니다. `TRAVEL_COMPATIBLE_DIR`로 별도 출력 경로를 지정할 수 있습니다. 각 실행은 다른 하위 폴더를 사용합니다.

**영상 사본 저장**과 **촬영 정보 JSON 저장**으로 두 파일을 내려받아 같은 폴더에 보관하세요. 다시 감상할 때 영상과 JSON을 함께 선택하면 촬영 시각·GPS를 유지합니다. 기존 사진과 함께 보려면 기존 사진도 함께 선택하세요. 현재 여행의 원본 목록은 자동으로 교체하지 않습니다. FFmpeg가 지원하는 메타데이터를 복사하지만 모든 제작사 전용 메타데이터의 보존을 보장하지 않으므로 원본을 보관하세요.
